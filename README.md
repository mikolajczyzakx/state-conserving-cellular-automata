# One-dimensional state-conserving cellular automata with the four-cell neighbourhood

This repository contains lookup tables (LUTs) of all one-dimensional state-conserving cellular automata with the **four-cell neighbourhood** and **three states**, together with the source code used to generate them.

## LUT definition

A **LUT** (lookup table) is the complete list of values of the local rule `f` of a cellular automaton, one value for every possible neighbourhood pattern. For the neighbourhood `N = (-1, 0, 1, 2)` the updated cell is the second one:

```
f(s1, s2, s3, s4) → {0, 1, 2},   where  s1, s2, s3, s4 ∈ {0, 1, 2}
```

For the neighbourhood size 4 and 3 states there are **3⁴ = 81** neighbourhood patterns, so a LUT consists of **81 values**, listed in the following order:

```
f(2,2,2,2), f(2,2,2,1), ... , f(0,0,0,1), f(0,0,0,0)
```

### Numeric interpretation

This ordering is equivalent to writing the LUT as a number in **base 3**, where:

- the **most significant digit** is `f(2,2,2,2)`,
- the **least significant digit** is `f(0,0,0,0)`.

So a LUT can be read as an 81-digit number in base 3, which gives every automaton a unique numeric identifier and a canonical total ordering.

## Line format

Each line of a file starts with a LUT (81 digits). The LUT is followed by the elements of the admissible set of transformations `T` that generates the automaton `F_T`, separated by spaces. Bypasses are listed first, then conditional swaps:

| Notation | Transformation | Action |
|---|---|---|
| `<p,q>_c` | conditional swap | pattern `p q c` becomes `q p c` |
| `[p,q,b]` | bypass | pattern `p q b` becomes `b p q`, pattern `~p q b` becomes `~p b q` |

Here `~p` denotes any state different from `p`. For example:

```
222222222111111111000001000...  <0,1>_0
222222222222211210222200000...  [0,1,2] [1,0,2] [1,1,2] <1,0>_0
```

A line containing only a LUT corresponds to `T = ∅`, that is, the identity rule. In `LUTs_all.txt` the automata of type 1 are reflections of the automata of type 0, so their lines list the set `T` of the reflected automaton `F_T`. The two shift rules are written without a set.

## Usage

The program requires Python 3.8 or newer and no external packages. Run it from the repository root:

```bash
python src/code.py                 # k = 3, results written to LUTs/
python src/code.py --verify        # additionally verify every LUT
python src/code.py --lut-only      # write LUTs only, without the sets T
python src/code.py -k 4            # another number of states, results written to LUTs/k4/
python src/code.py -o my_dir       # custom output directory
```

With `--verify` every generated LUT is checked for three properties: state conservation (Boccara–Fukś criterion), the expected type, and uniqueness within the whole set. After the run, the program prints the number of automata in each family. For the families of conditional swaps and bypasses, it also prints the value of the corresponding closed counting formula.
